# Automated DCF Valuation Model

## Objective
Build a Python program that forecasts a company's financial performance and estimates its intrinsic value using a discounted cash flow model.

## V1 Inputs
- Historical financial statements
- Revenue growth assumptions
- Operating margin assumptions
- Tax rate
- Depreciation and amortization assumptions
- Capital expenditure assumptions
- Working capital assumptions
- WACC
- Terminal growth rate
- Shares outstanding
- Cash
- Debt

## V1 Outputs
- Five-year financial forecast
- Unlevered free cash flow
- Present value of projected cash flows
- Terminal value
- Enterprise value
- Equity value
- Intrinsic value per share
- WACC and terminal growth sensitivity table
